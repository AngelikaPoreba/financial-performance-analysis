# Financial Performance Analysis

## Project Overview
This project analyzes the financial performance of a company using Budget, Forecast and Actual data.
The analysis focuses on comparing planned and actual results, identifying budget variances and analyzing differences between departments and quarters.
The project was created using Excel, SQL and Power BI.

## Tools
- Excel - data preparation, calculations and pivot tables
- SQL - data analysis and calculations
- Power BI - interactive dashboards and data visualization

## Dataset
The dataset contains financial data for 2024 and 2025.
It includes:
- Fiscal Year
- Department
- Quarter
- Budget
- Forecast
- Actual
- Variance
  The dataset contains 48 records across 6 departments and 4 quarters for each year.

  ## Excel Analysis
  In Excel, I prepared the data and created additional analysis columns:
  - Variance %
  - Budget Status

  I also created pivot tables to analyze:
  - Budget vs Actual by department
  - Budget vs Actual by quarter
  - Forecast vs Actual by quarter
  - Variance by department
  - Variance by quarter
 
  ## SQL Analysis
  The SQL analysis includes:
  - Summary of Budget, Forecast and Actual
  - Budget vs Actual by quarter
  - Budget vs Actual by department
  - Variance % by department
  - Budget Status by department
  - Forecast vs Actual by quarter
  - Forecast vs Actual by department
  - Department variance ranking
  - Budget, Forecast and Actual comparison by department
 
    ## Power BI Dashboard
    The Power BI report consists of three pages:

    ### 1. Executive Overview
    - Total Budget
    - Total Forecast
    - Total Actual
    - Budget vs Actual by Quarter
    - Variance by Department
    - Budget Status by Department
   
    ### 2. Variance Analysis
    - Budget Variance % by Department
    - Forecast vs Actual by Quarter
    - Forecast vs Actual by Department
    - Department Variance Ranking
    - Budget vs Forecast vs Actual by Department
   
    ### 3. Financial Insights
    - Total Budget Variance
    - Budget vs Forecast vs Actual by Quarter
    - Variance by Quarter
    - Key Insights
   
    ## Key Insights
    - Total Actual was above Total Budget by 54.64K USD.
    - Q1 had the highest positive budget variance of +37.69K USD, while Q4 had a negative variance of -22.09K USD.
    - Marketing had the largest positive budget variance of +40.10K USD, while IT had the largest negative variance of -9.96K USD.
    - Actual was above Forecast in every quarter, with the largest difference in Q2 (+32.91K USD).
